# 双人留言画板验收 · 2026-10-09

## 已验证

本机两个独立账号、独立 bundle ID、独立随机密码和数据目录，运行真实 AppKit/WebKit 桌面 App，连接隔离 PostgreSQL 后端。日常运行的 App 和正式待办未被这些测试替换。

`board-native-results.json` 记录通过状态、时间、画板脚本 SHA-256 和逐项结果：

- 入口打开独立窗口；真实鼠标绘画结束前，对方收到中间笔画和光标。
- 双向图形、中文文字、图片、撤销和重做。
- 绘制中接收对方元素，完整笔画保留；远程更新不打断正在输入的文字，不改变视野。
- 同一图形的位移和颜色并发修改均保留；撤销自己的位移不撤销对方颜色。
- 关闭时显示红点、不弹窗；打开清除提醒；跳转对方最新修改。
- 窗口外点击保持画板打开，窗口大小、位置与各自视野可恢复。
- 断网修改落盘，强制退出后重启补同步；后端真实停止再启动后，内容、图片和停机期间修改保留。
- 双方空闲时版本稳定，没有反复保存或排序抖动。
- 正常退出会完成未结束的文字输入并保存，重启后同步给对方。

自动图片验收通过原生文件选择回调提供固定 PNG；另一次使用实际 NSOpenPanel，通过系统“前往”定位 PNG 并点击“打开”，验证放置和对方接收。该次结果及截图留在 `artifacts/private/board-qa/native-picker-result.json` 与 `board-native-picker.png`。

`tests/board-service-checks.py` 运行两个后端进程，验证跨进程同步与光标、20 个并发创建的元素均到达两端、字段合并、删除标记、受保护的撤销、对象键重排后的幂等重试、图片存储、非法消息拒绝及跨空间访问隔离。原待办/爱心/SSE 回归通过，空闲 16 秒业务读取数不增加。

客户端测试覆盖离线队列序列化、在途请求不可变、过期确认、条件撤销、图层排序、JSONB 键顺序、图片占位元素，以及多图片请求大小分批。`pnpm build`、`pnpm check` 和 Docker 后端构建通过。桌面构建包含本地资源和开源许可。
